# Linkdrop

Linkdrop is a lightweight bookmark application that lets you save links (and short notes) so you can open and manage them later from any device. It’s intended for quick cross-device bookmarking — for example, when you’re on a computer that isn’t yours and want to save something to check later.

Key points
- Simple web UI (HTML) and a Java backend.
- User authentication (signup / login) so bookmarks are private to your account.
- Add, view and manage saved links from any device with a browser.

Features
- Create an account and log in.
- Add and categorize bookmarks (title, URL, optional note or tags).
- View and manage your saved links across devices.
- Basic search and list view for quick access.

Tech stack
- Frontend: HTML (static pages / templates)
- Backend: Java (serves pages / provides API for bookmarks and auth)
